Unggah berkas

PDF sebagai dokumen dasar, gambar logo (PNG/JPG) yang akan ditempelkan.

Atur posisi logo

Seret logo untuk memindahkan. Tarik titik emas di sudut untuk memperbesar / memperkecil.

100%
Logo hanya ditempel di halaman yang sedang dipilih. Gunakan tombol Zoom untuk memperbesar, lalu geser dua jari di area pratinjau untuk menggulir.

Unggah PDF

Pilih file PDF, lalu tandai halaman-halaman yang ingin dihapus.

Pilih halaman yang dihapus

Klik halaman untuk menandainya. Halaman yang ditandai (merah) akan dihapus dari hasil unduhan.

0 halaman ditandai untuk dihapus
Minimal satu halaman harus tersisa di PDF hasil.

Unggah PDF utama

Ini dokumen dasarnya. PDF lain akan disisipkan ke dalam dokumen ini.

Sisipkan dokumen PDF lain

Belum ada PDF yang dipilih untuk disisipkan.

Unggah file Word atau Excel

Format didukung: Word (.docx) dan Excel (.xlsx / .xls). Dikonversi langsung di browser, tidak diunggah ke server mana pun.

Pratinjau

Tata letak PDF mengikuti pratinjau di atas — bukan salinan piksel-persis file aslinya, terutama untuk Word.

Unggah gambar (JPG/PNG)

Pilih beberapa gambar sekaligus — satu gambar jadi satu halaman PDF, urutan bisa diatur sebelum digabung. Diproses langsung di browser.

Urutan halaman

Setiap gambar jadi satu halaman, ukuran menyesuaikan gambar (muat dalam A4).

Unggah PDF

Pilih file PDF yang mau dipangkas. Cocok untuk membuang ruang putih kosong di sekeliling isi (misalnya hasil cetak yang halamannya kebesaran).

Atur area crop

Kotak putus-putus emas menandai bagian yang akan DISIMPAN — di luar kotak akan dibuang. Geser kotak untuk memindah, tarik titik emas di sudut kanan-bawah untuk mengubah ukuran. Ini hanya memangkas batas halaman, isi di dalamnya tidak digambar ulang sama sekali — jadi kualitasnya tetap 100% sama seperti berkas aslinya.
